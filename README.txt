My Liliyana (ML)
Jalankan : node server.js   (Node.js 18+, tanpa npm install)
Buka     : http://localhost:3000   (port lain: PORT=8080 node server.js)
Online   : taruh folder ini di VPS/hosting Node dan pasang HTTPS. Di luar localhost HTTPS wajib, karena enkripsi browser hanya jalan di HTTPS.
Data     : data.json (akun, postingan, follow) dan folder uploads/ (foto/video). Backup keduanya.
Keamanan : akun diikat ke kunci tanda tangan di browser; server memverifikasi setiap aksi. Chat teman dan medianya terenkripsi end-to-end.
           Cocokkan "Kode keamanan" di chat dengan teman Anda untuk memastikan tidak ada pihak di tengah.
